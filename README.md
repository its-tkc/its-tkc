# 💼 Professional Experience

## 🥽 Virtual Labs — IIT Kanpur

### Unity / XR Developer

Developed interactive VR simulations for educational experiments in
**materials science and microscopy**.

The project covered nine experiments ranging from VR fundamentals and
microscope operation to material characterization, sample preparation,
microstructure observation, quantitative microscopy, and grain-size
analysis.

The applications were built for **Meta Quest 2** and also deployed as
browser-accessible WebGL experiences. My work included VR interaction
systems, data-driven experiment architecture, runtime debugging, and
performance optimization for standalone hardware.

**Tech:** Unity · C# · URP · OpenXR · XR Interaction Toolkit · XR Hands · Meta Quest 2 · Android · WebGL

---

## 🎯 OAKS Solutions Private Limited

### Unity Game Developer

Worked on educational games and interactive learning experiences for
children's applications, including

[**Titli**](https://play.google.com/store/apps/details?id=com.youroaks.kidztitli)
and
[**PeekAZoo**](https://play.google.com/store/apps/details?id=com.youroaks.kidz).

Both applications are published educational products by OAKS. PeekAZoo
combines interactive games, AR experiences, stories, rhymes, videos,
creative activities, and early-learning content, while Titli focuses
on interactive learning experiences for young children.

My work involved developing complete game modules within the existing
Unity application framework, integrating them into the host
application, creating AssetBundles, and deploying downloadable content
to AWS.

The applications use a modular content system where game content can
be downloaded, cached locally, and loaded at runtime.

Alongside game development, I also maintained and debugged the
Unity-based host application, investigating integration and runtime
issues when individual game modules failed.

**Tech:** Unity · C# · AssetBundles · AWS · Android

# 🎨 Creative Work

I have always been interested in more than just the programming side
of game development.

Over the years I've experimented with **2D illustration, character
design, game artwork, UI, promotional graphics, music and game audio**.
I've used Adobe Illustrator to create everything from game characters
and environments to application icons and store artwork.

I've also experimented with music production and game audio using
FL Studio. Eventually I learned an important lesson about game
production:

> **You can learn every discipline yourself, but you don't necessarily
> need to do everything yourself.**

Understanding the broader creative pipeline helps me communicate better
and build more cohesive interactive experiences.
